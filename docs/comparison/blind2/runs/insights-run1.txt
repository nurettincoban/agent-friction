Hooks
Shell commands that run automatically at lifecycle events such as before a tool call.
Why for you: Your two worst friction points were edits to already-applied migrations and a destructive `docker compose down -v`. A PreToolUse hook can block both before they happen, so you don't have to rely on Claude remembering.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{"type": "command", "command": "f=$(jq -r '.tool_input.file_path'); if echo \"$f\" | grep -q '/migrations/' && git ls-files --error-unmatch \"$f\" >/dev/null 2>&1; then echo 'Do not edit committed migrations; create a new numbered file' >&2; exit 2; fi"}]
      },
      {
        "matcher": "Bash",
        "hooks": [{"type": "command", "command": "jq -r '.tool_input.command' | grep -qE 'down -v|volume rm|DROP DATABASE' && { echo 'Destructive command blocked' >&2; exit 2; } || exit 0"}]
      }
    ],
    "PostToolUse": [
      {"matcher": "Edit|Write", "hooks": [{"type": "command", "command": "gofmt -l . && go vet ./... 2>&1 | head -20"}]}
    ]
  }
}
