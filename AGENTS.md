# Notes for coding agents working on agent-friction

(Yes, this project eats its own cooking. These are the things agents got wrong here.)

- Use `make check` (ruff, ruff format --check, mypy --strict, pytest). Run single tests with
  `uv run pytest tests/test_signals.py -k edit_miss`.
- Zero runtime dependencies: stdlib only under `src/`. Do not add packages to `dependencies`.
- The HTML report's markup and script live in `src/agent_friction/report/template.html`.
  Insert transcript-derived text with `textContent` only, never `innerHTML`.
- `examples/` is generated. Change code, then run `make examples`; never edit those files by hand.
- Fixture transcripts in `tests/fixtures/transcripts` are generated by
  `python -m tests.fixture_story`. Edit the story, not the JSONL.
- Never add a real transcript to the repo, even redacted.
- Any change to a signal or the scoring updates `docs/signals.md` or `docs/methodology.md`
  in the same change, with positive and negative tests.
- The Claude Code plugin lives in `.claude-plugin/` and `plugin/skills/`. Its skills run the
  bundled copy through `sh "${CLAUDE_PLUGIN_ROOT}/plugin/agent-friction"`, never a bare
  `agent-friction`. Keep `plugin.json`'s `version` equal to `__version__`;
  `tests/test_plugin.py` checks this and that every command in a skill parses.
