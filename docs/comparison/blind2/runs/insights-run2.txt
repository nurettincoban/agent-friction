Hooks
Shell commands that run automatically before or after Claude's tool calls and can block dangerous actions.
Why for you: Your worst friction was hard-to-undo actions: `docker compose down -v`, unrequested pushes, and edits to applied migrations. A PreToolUse hook enforces these rules every time, even if CLAUDE.md gets overlooked.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [{
          "type": "command",
          "command": "cmd=$(jq -r '.tool_input.command'); if echo \"$cmd\" | grep -Eq 'git push|down -v|--volumes'; then echo 'Blocked: ask the user before pushing or wiping volumes' >&2; exit 2; fi"
        }]
      },
      {
        "matcher": "Edit",
        "hooks": [{
          "type": "command",
          "command": "f=$(jq -r '.tool_input.file_path'); if echo \"$f\" | grep -q '/migrations/'; then echo 'Blocked: never edit an existing migration; create a new one' >&2; exit 2; fi"
        }]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "gofmt -l . && go vet ./... 2>&1 | head -20" }]
      }
    ]
  }
}
