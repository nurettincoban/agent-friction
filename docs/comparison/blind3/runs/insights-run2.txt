Hooks

Why for you: Your two most repeated corrections can be checked mechanically: console.* calls and edits to existing migrations. A hook catches them on the spot instead of relying on you to notice.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit",
        "hooks": [{
          "type": "command",
          "command": "f=$(jq -r '.tool_input.file_path'); if echo \"$f\" | grep -q 'prisma/migrations/'; then echo 'Existing migrations are immutable - create a new migration instead.' >&2; exit 2; fi"
        }]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{
          "type": "command",

        }]
      }
    ]
  }
