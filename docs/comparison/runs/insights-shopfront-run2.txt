Hooks
Shell commands that run automatically at lifecycle events, such as after every file edit.
Why for you: Your top friction was the same repeated mistake: using legacy_charge / payments/legacy.py. A PostToolUse hook can catch it the moment it is written, so you don't have to. It can also flag edits to the generated schema_gen.py.
// .claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "if grep -rnE 'legacy_charge|payments\\.legacy|from .*payments import legacy' src/shopfront --include='*.py' | grep -v 'src/shopfront/payments/legacy.py'; then echo 'BLOCKED: deprecated legacy payment path used. Use PaymentClient instead.' >&2; exit 2; fi; if git diff --name-only | grep -q 'src/shopfront/api/schema_gen.py'; then echo 'schema_gen.py is generated: edit api/openapi.yaml and run make codegen instead.' >&2; exit 2; fi"
          }
        ]
      }
    ]
  }
}
