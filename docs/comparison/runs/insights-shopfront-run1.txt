Hooks
Shell commands that run automatically before or after Claude uses a tool, and can block the action and explain why.
Why for you: Your two main mistakes are mechanical and easy to detect: editing `schema_gen.py` by hand, and introducing `legacy_charge` or `payments.legacy`. A hook can stop or flag these immediately, so you don't have to catch them yourself.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.file_path' | grep -q 'schema_gen.py' && { echo 'schema_gen.py is generated: edit api/openapi.yaml and run make codegen' >&2; exit 2; } || exit 0"
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "grep -rnE 'legacy_charge|payments\\.legacy|from \\.legacy' src/shopfront --include=*.py | grep -v 'payments/legacy.py' && { echo 'Deprecated payment code detected: use PaymentClient instead' >&2; exit 2; } || exit 0"
          }
        ]
      }
    ]
  }
}
