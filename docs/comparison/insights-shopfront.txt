Hooks
Shell commands that run automatically before or after Claude uses a tool.
Why for you:
 Your repeated mistakes are mechanical: editing schema_gen.py and calling legacy payment code. A PreToolUse hook can block an edit to those files before it happens, so you don't have to catch it in review.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "f=$(jq -r '.tool_input.file_path // empty'); case \"$f\" in *schema_gen.py) echo 'schema_gen.py is generated: edit api/openapi.yaml and run make codegen' >&2; exit 2;; *payments/legacy.py) echo 'legacy payments module is deprecated: use PaymentClient' >&2; exit 2;; esac; if jq -r '.tool_input.new_string // .tool_input.content // empty' | grep -q 'legacy_charge'; then echo 'legacy_charge is deprecated: use PaymentClient.charge()' >&2; exit 2; fi"
          }
        ]
      }
    ]
  }
}
