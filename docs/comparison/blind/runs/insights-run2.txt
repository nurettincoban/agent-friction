Hooks
Shell commands that run automatically before or after Claude's tool calls, and can block an action.
Why for you: Your most-repeated corrections were edits to generated files and to the dead `transforms/` package. A PreToolUse hook blocks those edits before they happen, so you don't depend on Claude remembering CLAUDE.md. A PostToolUse hook can also run fast lint after every Python edit.
// .claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": ".claude/hooks/guard.sh" }]
      }
    ]
  }
}

# .claude/hooks/guard.sh  (chmod +x)
#!/usr/bin/env bash
f=$(jq -r '.tool_input.file_path // empty')
case "$f" in
  */transforms/*) echo "transforms/ is dead legacy code. Edit tidewater/transform/ instead." >&2; exit 2;;
  */generated/*|*_generated.py) echo "Generated file: edit the Avro schema and regenerate." >&2; exit 2;;
esac
exit 0
