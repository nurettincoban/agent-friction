Custom Skills
Turns your repeated 'watch the build' request into a single /watch-build command with consistent behavior.
Why for you:
 You made the same request in all 3 sessions, and each time Claude improvised a polling loop. A skill would lock in efficient waiting plus a clear final report every time.
mkdir -p .claude/skills/watch-build && cat > .claude/skills/watch-build/SKILL.md << 'EOF'
---
name: watch-build
description: Watch the latest CI build until it finishes and report the result
---
1. Find the latest run for the current branch (e.g., `gh run list --branch $(git branch --show-current) --limit 1`).
2. Wait on it with ONE blocking command: `gh run watch <id> --exit-status`. Do not poll repeatedly.
3. Report: PASS/FAIL, duration, and the run URL.
4. If it failed, run `gh run view <id> --log-failed`, summarize the root cause, and propose a fix.
EOF
